# Тренажер з інформатики

Пояснення і вправи для учнів з телефона (ліцей № 13, Полтава). Сайт: https://kovdmitro13-gif.github.io/trenazher/

- `src/app.css`, `src/app.js` — оформлення і рушій (спільні для всіх тем).
- `src/lesson-*.js` — дані однієї теми (об'єкт `LESSON`).
- `node build.js` збирає сторінки в корінь репозиторію (їх віддає GitHub Pages) і однофайлову версію `artifact/trenazher.html`.
- `tools/e2e.js` — прогін усіх вправ у браузері на ширині телефона.

Python виконується в браузері через Skulpt 1.2.0. Списків учнів і результатів у репозиторії немає.
